# DesktopCal 중계 (desktopcal-feed)

DesktopCal 달력 앱의 티커 띠가 **키 없이** 쓰는 공공데이터 사본입니다.
GitHub 자동 작업이 10분마다 받아 `gh-pages` 가지에 올리고, GitHub Pages 가 공개 주소로 냅니다.

- 공개 주소: https://gityauls.github.io/desktopcal-feed/
- 앱 쪽: `marquee_core/feed.py` (어떤 요청이 어느 파일인지 — 이 저장소의 `feed.py` 는 그 복사본)
- 원본: 앱 저장소의 `relay/` 폴더 (이 저장소는 거기서 옮겨 온 것 — 고칠 때는 앱 저장소에서)

|---|---|---|
| 기상특보 | 10분 | 기상청 |

중계하지 않는 것: 아파트 실거래(지역이 너무 많다), 재난문자(부르는 PC 의 IP 를 등록해야 한다), 주가·공시(개인 키).

## 언제 도나
- 예약(cron) 10분마다. GitHub 예약 실행은 늦거나 빠질 수 있어서(새 저장소에서 몇 시간 동안 한 번도 안 돈 적이 있다, 2026-10-10),
  손으로 부르거나 main 에 코드를 올려 시작한 실행은 **최근 30분 안에 예약 실행이 없으면 7분 쉬고 다음 실행을 부른다**.
  예약이 돌기 시작하면 이어 부르기는 저절로 멈춘다.
- 다시 시작하려면: Actions → relay → Run workflow (또는 main 에 아무 커밋).

## 키
저장소 Settings → Secrets and variables → Actions 에 `DATA_GO_KR_KEY` · `EXIM_KEY` · `KOBIS_KEY`.
키는 실행 기록·파일 어디에도 남지 않습니다 (주소·매개변수·예외 글을 찍지 않는다).

## 파일 모양
`{"fetched": "2026-10-10T14:04:12", "status": 200, "text": "<원래 응답>"}` — 앱은 원래 응답을 그대로 해석하고,
받은 시각이 너무 오래되면(중계가 멈춤) 쓰지 않습니다.
